# Plugin migration reflections

Read every completed reflection before starting another plugin. Add a new file
only after that plugin has been published and installed successfully in the
allowed Windows and Linux verification environments.

## Required checklist

1. Record exact upstream, fork, and imported revisions.
2. Record the package name and PEP 440 version decision.
3. Identify which workflow commands were copied from the verified fork.
4. Record monorepo-only path and publishing changes separately.
5. Record Windows and Linux release URLs and installation smoke results.
6. Capture reusable failures, fixes, and constraints for the next migration.
